Setup

Secrets are encrypted with Windows DPAPI for your Windows user. Saved secrets are never sent back to this page; blank secret fields keep the existing secret.

Create your bot in the Discord Developer Portal. Open your application → Bot to get/reset the token. Keep it private.

Use the Application ID on your app’s General Information page. For server and channel IDs, enable Developer Mode in Discord’s Advanced settings, then right-click the server or channel and choose Copy ID.

Restart the app after changing the Discord bot token or application/server IDs. IDs are not secret, but are stored locally.

Factory reset

This permanently deletes saved settings, encrypted service/Discord tokens, local logs, and the local .env file. Automatic sync will stop. This cannot delete messages already sent to Discord or revoke tokens at their providers.
