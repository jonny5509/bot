# ESP32 edition

The separate ESP32-WROOM-32 firmware is in [firmware/](firmware/README.md). It provides a Wi-Fi onboarding portal, a LAN dashboard, timer preview, manual sync, and optional 10-minute automatic sync.

This is an initial hardware-targeted scaffold, not a claim of hardware-tested production firmware. Build and test it on your ESP32 with valid provider credentials and a trusted TLS CA bundle before enabling automatic sync. See the firmware README for setup and security caveats.
